в RTL есть 3 главных семейства функций для поиска:
    1. getBy... (синхронный, строгий):
        - ищет прямо сейчас. если не наёшл - выбрасывает ошибку, прерывая выполнение;
        - использовать только при полной уверенности, что элемент должен быть на экране;
    2. queryBy... (синхронный, мягкий):
        - ищет прямо сейчас. если не нашёл - возвращает null;
        - использовать ТОЛЬКО для проверок того, что элемента НЕТ на экране (в связке с .toBeNull()
        или .not.toBeInTheDocument());
    3. findBy... (асинхронный, ждун):
        - возвращает Promise. ждёт до 1 секунды. если элемент появился - отдаёт его. если нет - выбрасывает ошибку;
        - использовать когда элемент появляется после загрузки, клика или анимации;
