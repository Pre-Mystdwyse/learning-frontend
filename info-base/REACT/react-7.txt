в CSS есть понятие контекста наложения. если у родительского элемента стоит
overflow: hidden, z-index, или transform, то дочерний элемент, даже если у
него position: fixed и z-index: 9999, никогда не сможет выйти за пределы
родителя или перекрыть другие элементы на странице. например, если это модалка,
написанная в какой-то условной середине дерева DOM, то она окажется обрезанной
или спрятанной под соседними родителю элементами;
чтобы решить эту проблему, в реакте есть порталы (createPortal). аналогия:
    маг (например, комопнент QuestCard) кастует заклинание призыва дракона
    (модалку). если он кастует его в тесной пещере (внутри <article>), дракону
    не хватит места. маг открывает портал (createPortal) и переносит точку
    появления дракона прямо на главную площадь города (document.body), хотя
    сам маг фактически остаётся в пещере;

синтаксис:
    import { createPortal } from 'react-dom';

    function MyComponent() {
        return (
            <div>
                <p>Я в пещере</p>
                {createPortal(
                    <div className="modal">Я на площади (в body)</div>,
                    document.body
                )}
            </div>
        );
    }

физически в HTML модалка окажется в <body>. но в виртуальном DOM реакта она
остаётся внутри MyComponent. это значит, что если в модалке произойдёт клик,
событие всплывёт в MyComponent, и модалка по-прежнему будет иметь доступ
к контексту (HeroProvider);
